# VST 3.0.0

### Umbenennung

- **GonoPBX heißt jetzt VST** (Vermittlungsstelle). Neues Logo, neues Farbschema (Blau), neue Repository-Adresse `ankaios76/vst`. Technische Namen bleiben aus Kompatibilitätsgründen bestehen: MQTT-Topics `gonopbx/...`, `gonopbx_call:` und `@gonopbx.local`.
- Neue Dokumentation: README, ausführliche Installationsanleitung auf Deutsch und Englisch mit Screenshots (`docs/`).

### Sicherheit und Fehlerbehebungen

- Kein Standard-Adminpasswort mehr: ohne `ADMIN_PASSWORD` erzeugt das Backend beim Start ein zufälliges und schreibt es ins Log.
- Der Installer sendet keine Telemetrie mehr.
- Rufnummernblöcke wie `03023125100-03023125199` ließen das Backend den Speicher füllen. Der Teil nach dem Bindestrich ersetzt jetzt die letzten Ziffern der ersten Nummer, Blöcke sind auf 1000 Nummern begrenzt.
- Rufnummernübermittlung (`P-Asserted-Identity`) wird auf dem ausgehenden Kanal gesetzt; Telekom All-IP nutzt weiter `P-Preferred-Identity`.
- Entfernt: veraltete Skripte (`deploy.sh`, `setup.sh`, `fix-typescript.sh`), Backup-Dateien und die alte Projekt-Webseite aus dem Repository.
